# 🏠 HomeVision 3D
### Online Interior Design Platform

## 📌 Project Description
HomeVision 3D is an online platform that helps users design and visualize their future home interiors.

Users can choose room templates, add furniture, change wall colors and materials, and view their designs using an interactive 3D editor.

## 🎯 Project Objectives
- Make interior design easier and more accessible.
- Allow users to visualize rooms in 3D.
- Provide furniture and material customization.
- Allow users to save and manage design projects.
- Develop a web application using Java Spring Boot.

## 👥 Target Users
- Homeowners
- People building new houses
- People planning renovations
- Interior design enthusiasts

## ⚙️ Technologies
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- Thymeleaf
- PostgreSQL
- HTML, CSS, JavaScript
- Three.js
- Maven

## ✨ Main Features
- User registration and login
- Room template selection
- Interactive 3D room editor
- Furniture catalog
- Wall color and material customization
- 3D room visualization
- Save and edit design projects
- User profile

## 🏗️ System Architecture
Frontend → Controller → Service → Repository → Database
